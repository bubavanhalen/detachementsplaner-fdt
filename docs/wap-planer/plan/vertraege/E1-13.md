# Vertrag E1-13 – Wochenraster: Verschieben, Mehrfachauswahl, Kopieren, Eintragsaktionen

Entwurf 01.10.2026, ausgerichtet auf `ui-richtlinie.md` 5.1 (Ctrl-/Shift-Klick, Shift+Ziehen), 5.5–5.8, 5.10 (Eintrag), 11.5, 13.3. Grundlage Beschrieb 4.6, 5.1, 6; `_konventionen.md`. IDs: R-4.6-61, R-5.1-14, -16, -20 bis -22, R-6-01, R-11-11.

Nachführung Gate 0 (02.10.2026): R-5.1-20 nach Q-009 K-1 – der Auswahlrahmen entsteht nur mit Shift+Ziehen; der Test `[R-5.1-20]` prüft zusätzlich: Shift+Ziehen über drei Blöcke → drei gewählt, kein neuer Block; Ziehen ohne Taste auf leerer Fläche → neuer Block (Verhalten aus E1-12).

## 1 Verhalten und Befehle

| Geste / Taste | Wirkung | Befehl (E1-03) |
| --- | --- | --- |
| Ziehen am Eintrag | verschieben, einrasten 15 Min und Spaltengrenzen (R-5.1-14); Zeitschild mit neuer Zeit, Tag, Spalten; Original blass | `moveEntries` |
| Ziehen an Griffen oben/unten, links/rechts | Beginn/Ende bzw. Spaltenspanne ändern | `updateEntry` |
| über die Tagesgrenze | Zieltag; Vorwarnung im Zeitschild «‹Spalte› gibt es am ‹Tag› nicht: nur ‹Spalte› (gleiche relative Lage) · Befund P1» (R-5.1-16) | `moveEntries` |
| Ctrl beim Loslassen | Kopie ablegen; Zeitschild «Kopie» | `copyEntries` |
| Ctrl+Klick / Shift+Klick | Auswahl umschalten / Rechteckbereich (R-5.1-20) | – |
| Shift+Ziehen | Auswahlrahmen, auch auf einem Eintrag beginnend (UI-Richtlinie K-1) | – |
| Mehrfachauswahl verschieben / Kategorie / Löschen | ein Undo-Schritt (R-5.1-21) | `moveEntries`, `updateEntries`, `deleteEntries` |
| Ctrl+C / Ctrl+X / Ctrl+V | kopieren/ausschneiden/einfügen am Zellzeiger bzw. gleicher Wochentag und Zeit der aktuellen Woche (R-5.1-22, auch zwischen Wochen) | `copyEntries`, `deleteEntries` |
| Ctrl+D | duplizieren unmittelbar anschliessend (UI-Richtlinie F-6) | `copyEntries` |
| A / Kontextmenü «Auch an anderen Tagen …» | Dialog (Abschnitt 2), unabhängige Kopien, ein Undo-Schritt (R-6-01, F-22) | `copyEntryToDates` |
| X | Streichen ↔ bestätigt | `updateEntries` |
| Entf | Löschen, Toast «‹n› Einträge gelöscht» mit «Rückgängig» | `deleteEntries` |
| Teilblock bearbeiten | Titel/Verschieben wirkt auf alle verknüpften Teilblöcke (ein Eintrag, R-4.6-61) | – |

## 3 Leistung (R-11-11)

Während des Ziehens wird nur die Markenebene neu gezeichnet; das Layout der betroffenen Tage wird erst beim Loslassen neu berechnet. Messung: p95-Bildzeit ≤ 16,7 ms, keine Aufgabe > 50 ms während 2 s Ziehen mit dem synthetischen Plan (ADR-010 Abschnitt 8).
