# Vertrag E1-09 – Personenliste aus Datei

Entwurf Runde 2, 01.10.2026. Abhängig von E1-02f für den PDF-Teil von R-11-05 (PL0-11). Grundlage Beschrieb 4.1, 11; Prompt §8 («nur Grad, Name, Vorname und Funktion … verwirft alle übrigen Spalten, ohne sie zwischenzuspeichern. Das Dateiformat schlägst du an Gate 0 vor»); `_konventionen.md`. IDs: R-4.1-11, R-11-05. Modul `src/io/wap-persons/`, Befehl in `src/model/wap/commands/persons.ts`.

## 1 Dateiformat (Plan P-8; an Gate 0 am 02.10.2026 angenommen, Entscheid 8)

- **CSV** (`.csv`): UTF-8 mit oder ohne BOM, Trennzeichen `;` oder `,` (automatisch aus der Kopfzeile), Anführungszeichen nach RFC 4180. **Kopfzeile Pflicht** mit den Spalten `Grad`, `Name`, `Vorname`, `Funktion` (Gross/Klein und Leerraum egal, Reihenfolge frei). Weitere Spalten sind erlaubt und werden verworfen.
- **Excel** (`.xlsx`): erstes Blatt, erste nicht leere Zeile ist die Kopfzeile, sonst wie CSV. Gelesen mit `src/io/xlsx-drawing` (kein SheetJS).
- Beispiel (fiktiv): `Grad;Name;Vorname;Funktion` / `Lt;Muster;Beispiel;Zfhr`.
- Begründung: Die Personalliste der Armee liegt meist als Excel vor; eine feste Kopfzeile macht die Zuordnung eindeutig, ohne dass Inhalte anderer Spalten angesehen werden müssen.
